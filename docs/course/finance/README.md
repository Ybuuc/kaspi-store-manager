# Финансовая модель: ЛЗ3 и ЛЗ8

Модель пересчитана для адаптации существующего архива командой из **2 человек**.
Это управленческий сценарий, не фактическая выручка и не обещание экономии.
Интервью отсутствуют: выигрыш 20 часов/месяц остаётся гипотезой.

Запуск: `python tools/finance.py`. Входы и отдельный список допущений — inputs.json;
выходы — results.json и budget-12-months.csv. Notebook finance.ipynb запускает тот же код.
Все суммы в KZT, налоги не включены. Денежные выплаты студентам не предполагаются:
2500 KZT/час — оценка альтернативной стоимости времени, а не ставка оплаты.

Формулы: I = часы разработки × ставка + обучение × ставка + оборудование.
M = инфраструктура + лицензии + поддержка × ставка. TCO36 = I + 36M.
B = сэкономленные часы × ставка. ROI = (36B − TCO36)/TCO36.
Окупаемость = I/(B−M), только если B>M. Без положительного потока — N/A.
Стресс 1: TCO ×1.3; стресс 2: эффект ×0.5. Бюджет12 = I +12M.
Стоимость пользователя = бюджет12/(12×число пользователей).
Точка безубыточности = ceil((I/12+M)/(цена−переменные затраты)).
Для внутреннего склада эта последняя формула — учебный сценарий сервиса;
реальная отдача оценивается экономией времени, не продажей подписок.

Сравниваются публичное облако, собственное оборудование, открытый стек на VPS
и бесплатное демо на уже имеющемся ноутбуке. Все варианты используют открытое ПО;
«open source» не означает нулевой TCO. Ничего не арендуется и не оплачивается.
Официальные цены и статус подтверждения находятся в inputs.json → sources.
Для VPS цена предварительная: прямой официальный URL отвечает 404, поэтому
вариант не является окончательной коммерческой оценкой. Пересчитать после подтверждения.
Рекомендация для курса: existing_laptop_demo; инфраструктурные варианты — только на бумаге.
