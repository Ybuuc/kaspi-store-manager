# Прогноз, а не обещание даты

Источники: data/issues.json выгружен через GitHub connector 19.11.2026.
Снимок получен до создания новых задач #71–73. Коллекция содержит 46 issues, без PR; первая страница до 100 записей покрывает
всю коллекцию на дату выгрузки. Сохраняются URL, created_at, closed_at и state.
Единица — закрытые issues за полную неделю; нулевые недели включены.
Частичная текущая неделя исключена, переоткрытия по одному closed_at не моделируются.
Эпики и подзадачи не отфильтрованы: это административный поток, не чистая velocity команды.

`python tools/forecast.py`: 10000 прогонов, seed=20261119, bootstrap недель
с возвращением; объём — открытые issues на дату выгрузки. Даты и P50/P70/P85/P95
сохранены в forecast.json; гистограмма и CDF — forecast.png. Notebook воспроизводит код.
Массовое закрытие учебных задач в один день делает историю нестабильной;
прогноз не следует использовать как обязательство перед магазином.

Story points и planning poker команды отсутствуют. Сравнение с детерминированной
оценкой и протокол голосования на 10 историях **не выполнены**; шаблон ниже
не является результатом реальной сессии.

|---|---|---|---|---|

доступность и отсутствие существенных блокировок перед принятием прогноза.
