# ЛЗ2: сравнение моделей поставки

| Критерий | Госдокументооборот по тендеру | Стартап мобильного продукта | Миграция банка в облако |
|---|---|---|---|
| Регуляторная формальность | Высокая: согласованные стадии | Зависит от данных | Высокая: контроль рисков |
| Определённость scope | Контрактная базовая линия | Низкая: проверка гипотез | Целевое состояние + уточняемые волны |
| Цена поздней ошибки | Высокая: приёмка/контракт | Ненужный продукт | Потеря данных/доступности |
| Обратная связь | Демонстрации вех | Частые эксперименты | Проверка каждой миграционной волны |
| Возможность отката | План по этапам | Feature flags/малые релизы | Обязательный rollback и сверка данных |
| Модель | Поэтапная с итерационной разработкой | Итерационная discovery/delivery | Гибрид: gated waves + итерации |

# ЛЗ3: бизнес-кейс и проект устава

Проблема-гипотеза: дублирование данных и ручной расчёт склада/прибыли.
Метрика: время ежемесячного учёта и доля исправлений; базовый замер отсутствует.
Варианты: ничего не менять (нулевая разработка, ручная работа остаётся), купить
готовое решение (нужны коммерческие предложения и проверка выгрузки данных),
адаптировать архив (сохранение данных и функций), переписать всё (лишний риск миграции).
Рекомендация: адаптация архива, бесплатное локальное демо, затем UAT.
Цифры и чувствительность — finance/inputs.json и finance/results.json.

**Устав, проект для согласования.** Продукт — единый архивный Kaspi Stock.
Команда — 2 человека, распределение в team-plan.md. Спонсор/заказчик не назначен.
Объём — US-01…US-18 плюс исходные склад/Excel/Kaspi/парсер/чат.
Вне объёма — платные подписки, покупка облака, неподтверждённые интервью и production-SLA.
Критерии приёмки: исходные данные сохранены по каждому полю; единый каталог;
роли/CSRF/история проверяются тестами; сценарии UAT приняты второй командой.
Ограничения: внешний Kaspi требует разрешённого токена, ИИ необязателен,
производственные НФТ измеряются отдельно. Бюджет — экономическая оценка времени,
не обязательство заплатить. Вехи: данные/схема → функции/регрессия → UAT/защита.
Изменения scope проходят issue → оценка влияния → решение двух участников и заказчика.
Риски: потеря данных, незакрытая UAT, недоступность API, неподтверждённый эффект.
Подписи спонсора и команды: не получены. Защита на 5 минут не проводилась.
