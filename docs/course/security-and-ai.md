# ЛЗ12: карточка ИИ-функции и честный статус eval

Ценность: навигационная помощь в складской программе без записи в БД.
Бизнес-метрика: время самостоятельного поиска операции; исходный замер не получен.
Цель качества: ≥90% корректных справочных ответов,0 попыток изменения данных.
Baseline без ИИ: локальная справка по правилам в assistant_reference.py.
Опциональный ИИ: уже имеющийся Gemini либо установленная пользователем Ollama-модель.
Ни банковская карта, ни платный API не требуются для основной системы.
По умолчанию AI_PROVIDER=off. Числовые ответы склада остаются локальными;
внешнему Gemini не передаются строки базы или история заказов из кода приложения.
При включении Gemini передаётся текст сообщения и системная инструкция;
пользователь может сам вписать ПДн, поэтому UI предупреждает об этом.
ИИ не получает инструментов записи/SQL, рекомендации проверяет человек.
Категория риска — ограниченный информационный помощник по нашей внутренней оценке,
не юридическая классификация; нет автоматических решений о людях/кредите/работе.

`ai/eval.json`:30 новых синтетических вопросов и эталонных смыслов, подготовленных
ассистентом для проверки проекта. Студентам нужно самостоятельно проверить эталоны
и дополнить реальные ошибки; это не утверждение об их самостоятельном авторстве.
`python tools/evaluate_assistant.py` измеряет **baseline без ИИ**;
результат baseline-results.json является настоящим прогоном правил, не оценкой LLM.
`--backend ollama --model <установленная-модель> --output ...` запускает бесплатный
локальный LLM-прогон. Модель в среде не установлена; настоящий LLM eval не выполнен.
Нельзя считать критерий ЛЗ12 о замере выбранной модели закрытым baseline-оценкой.

Стоимость на бумаге: Gemini3.5Flash-Lite, standard, вход0.30USD/1M,
выход2.50USD/1M: [официальный прайс](https://aistudio.google.com/docs/pricing#gemini-3.5-flash-lite),19.11.2026.

×10 нагрузки=74USD. Длины800/200 — допущения, не реальные замеры Gemini.
Открытый tiktoken используется как proxy для токенизации eval-файла;
его числа не равны счётчику Gemini. Скрипт ai_cost.py сохраняет фактические proxy-counts.
