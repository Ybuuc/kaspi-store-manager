# ЛЗ 7 — Сәйкестік чек-листі

Жоба: Kaspi Store Manager  
Күні: 13.10.2026  
Мәртебе: бастапқы бағалау; заңдық сәйкестік ресми расталмаған.

## 1. Жеке деректер картасы

| Дерек | Қазіргі мәртебе/мақсат | Ықтимал құқықтық негіз | Сақтау орны | Қолжетімділік | Сақтау мерзімі |
|---|---|---|---|---|---|
| Қызметкер логині/аты | Аутентификация болса қажет; нақты схема белгісіз | Қолданылатын заңға сай негізді нақтылау қажет | User Store орны бекітілмеген | Қызметкер өзі және уәкілетті әкімші | Саясат бекітілмеген; аккаунт жойылғанда жою тәртібі қажет |
| Құпиясөз | Қажет болса тек salted hash | Аккаунтты қорғау үшін заңды негіз нақтылансын | User Store | Құпиясөздің ашық түріне ешкім қол жеткізбеуі тиіс | Аккаунт белсенділігі; кейін қауіпсіз жою |
| Рөл/рұқсат | Қажет болуы мүмкін | Қолжетімділікті басқаруға қажетті негізді нақтылау | User Store | Әкімші және уәкілетті тұлға | Қызметтік қажеттілік аяқталғанша |
| Клиент аты/байланысы | MVP-де қажет екені расталмаған | Жинауға дейін мақсат пен заңды негіз бекітілсін | Белгісіз; әзірше жинамау ұсынылады | Қажетті рөлдер ғана | Бекітілмеген; қажеттілік болмаса жинамау |
| Тапсырыс деректері | Функция жоспарланған, схема расталмаған | Шарттық/заңдық негізді тексеру керек | Деректер қоймасы расталмаған | Уәкілетті қызметкерлер | Бизнес және заң талаптарымен бекітіледі |
| IP/қауіпсіздік логтары | Жүйе іске қосылса болуы мүмкін | Қажеттілік пен заңды негізді нақтылау | Лог сақтау орны белгісіз | Жүйе әкімшісі, шектеулі | Қысқа мерзім бекітіліп, автоматты жою қажет |

Кестедегі негіздер заңдық қорытынды емес, тек тексеруге арналған болжамдар. Қазақстанның жеке деректер туралы заңнамасына және нақты өңдеу мақсатына сай негізді жауапты тұлға/заңгер растауы тиіс. Қажет емес деректерді жинамау ұсынылады.

## 2. Сәйкестік чек-листі

| Тексеру тармағы | Мәртебе | Қажетті әрекет/дәлел |
|---|---|---|
| Жеке деректердің толық тізімі бар | Ашық | Деректер картасын нақты схемаға сәйкестендіру |
| Әр өрістің мақсаты мен заңды негізі бар | Ашық | Жауапты тұлғаның мақұлдауы |
| Деректер минимизациясы сақталған | Тексеру қажет | MVP-ден қажетсіз өрістерді алып тастау |
| Деректердің физикалық/бұлттық орналасуы белгілі | Ашық | Hosting және database орналасуын құжаттау |
| Рөлдер мен қолжетімділік матрицасы бар | Жоспарланған | RBAC тесттері |
| Құпиясөз қауіпсіз hash түрінде сақталады | Кодпен расталмаған | Код ревью және тест |
| TLS іске қосылған | Ортаға тәуелді | Deploy конфигурациясын тексеру |
| Сақтау және жою мерзімдері бекітілген | Ашық | Retention policy |
| Backup және restore тәртібі бар | Ашық | Restore test дәлелі |
| Инцидентке әрекет ету тәртібі бар | Ашық | Incident response нұсқаулығы |
| Репозиторийде құпия жоқ | Gitleaks сканерлеуі сәтті өтті | Сканерлеу есебінде құпиялар табылмаған; кейінгі өзгерістерді де тексеру қажет |
| Тәуелділіктер мен конфигурация сканерленген | Ішінара тексерілді | Trivy іске қосылды, бірақ қолдау көрсетілетін тәуелділік және конфигурация файлдары табылмаған; толық сканерлеу үшін жоба файлдарын тексеру қажет |

## 3. AI компоненті
Қазіргі жоба сипаттамасында AI/ML функциясы жоспарланған мүмкіндіктер арасында көрсетілмеген. Бастапқы бағалау: AI компоненті жоқ / қолданылмайды. Мұны нақты код пен тәуелділіктерді тексергеннен кейін ғана растауға болады.

Егер AI кейін қосылса, мақсаты, кіріс деректері, шешімге әсері, адам бақылауы, түсіндірмелілік және қате нәтиже үшін жауапкершілік бағалануы тиіс. Қолданылатын заң мен use case анықталмайынша тәуекел санатын дәлелсіз белгілемеу керек.
