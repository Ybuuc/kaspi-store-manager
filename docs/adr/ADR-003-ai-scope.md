# ADR-003: справка локально, генеративный ИИ только опционально

Статус: принято для бесплатной учебной поставки; rollout LLM отложен до eval.
Контекст: исходный архив уже имеет Gemini, но основной учёт не должен зависеть
от платного сервиса, ключа или передачи персональных данных.
Варианты: обязательный Gemini; локальная Ollama; справочник без ИИ + опциональные адаптеры.
Выбрано последнее: существующий чат сохраняется, простые вопросы решаются локально;
внешний ИИ включается явно. Обязательный Gemini отвергнут из-за зависимости от API;
обязательная Ollama — из-за неизвестной памяти ноутбука.
Последствия: склад и справка работают офлайн; реальный LLM quality gate ещё не пройден,
поэтому автоматизация операций и рекомендации по ценам не включаются.
Решение по ИИ для публичного применения: пока не делаем до независимых эталонов,
настоящего eval и подтверждённой политики данных. Это не блокирует исходный учёт.
