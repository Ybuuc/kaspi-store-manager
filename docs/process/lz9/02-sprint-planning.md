сүйенген **жоба**, бағаларды GitHub issue-лердегі нақты бағамен салыстырып бекітіңіз.

Алдын ала шарттар:
- Capacity ≈ 7 сағ × 0,65 ≈ **4,5 сағ/апта** ([team-raci-capacity.md](../../planning/lz5/team-raci-capacity.md)).

  яғни толық Increment 1 бір спринтке сыймайды; спринтте ең құнды дәйекті бөлік алынады.
