# Как показать учебную ИС без кабинета продавца Kaspi

Это сценарий для локальной демонстрации. Все товары, суммы и заказы, которые вы введёте, будут **учебными данными**, а не сведениями из Kaspi. Доступ к кабинету продавца, токен API, платный хостинг и PostgreSQL для показа не нужны.

## Подготовка

1. Выполните шаги 1–4 раздела [«Как скачать и запустить ИС локально»](../../README.md#как-скачать-и-запустить-ис-локально). Пока не запускайте сервер: сначала добавьте администратора и учебные заказы в том же терминале.
2. Помимо учётной записи `employee` создайте администратора. В Windows PowerShell команда выглядит так:

   ```powershell
   .\.venv\Scripts\python.exe -m flask --app app:create_app create-user --role admin admin
   ```

   В macOS/Linux замените путь к Python на `.venv/bin/python`. Пароли задаются при выполнении команды; используйте отдельные пароли для двух пользователей.
3. Добавьте два учебных заказа с датой показа. В Windows PowerShell:

   ```powershell
   $demoDate = (Get-Date).ToString('yyyy-MM-dd')
   .\.venv\Scripts\python.exe -m flask --app app:create_app add-demo-order $demoDate 2500.00 "Жаңа"
   .\.venv\Scripts\python.exe -m flask --app app:create_app add-demo-order $demoDate 1200.00 "Орындалды"
   ```

   Эти команды добавляют заказы при каждом запуске. Если они уже выполнены, повторять их не нужно. Суммы приведены только как пример для демонстрации.
4. Запустите приложение по шагу 5 README и откройте `http://127.0.0.1:5000`.

## Порядок показа

1. Войдите как `employee`. Добавьте товар через **«+ Жаңа тауар»**, например «Учебный чай», SKU `DEMO-TEA`, категорию «Напитки», цену `1500.00` и остаток `2`. SKU должен быть уникальным: при повторном показе выберите другое значение.
2. Откройте карточку и задайте порог низкого остатка `3`. Покажите предупреждение в карточке и списке. Измените остаток на `4` и убедитесь, что предупреждение исчезло.
3. Измените цену на `1600.00`. Затем откройте **«Тапсырыстар»**: переведите учебный заказ из `Жаңа` в `Өңделуде`, затем в `Орындалды`. Покажите фильтр по статусу и то, что конечный статус больше не меняется.
4. Выйдите и войдите как `admin`. Откройте **«Қойма есебі»** и сравните числа со списком активных товаров. В карточке товара откройте **«Баға тарихы»**: там видны старая и новая цена, время и пользователь.
5. Откройте **«Сату статистикасы»** и выберите сегодняшнюю дату в обоих полях. Число заказов учитывает все статусы, а сумма — только `Орындалды`. Это сумма учебных заказов, не выручка магазина.
6. Откройте **«Өзгерістер журналы»** и покажите записи изменения товара, цены и остатка с пользователем и временем. В **«Әкімші»** покажите список ролей. При входе как `employee` административные разделы не видны и закрыты даже по прямой ссылке.

После показа остановите сервер сочетанием **Ctrl+C**. База остаётся в `instance/kaspi-store-manager.sqlite3`; способ сделать её резервную копию указан в README. Демонстрационные суммы и даты не используйте как показатели реальных продаж или метрики спринта.
