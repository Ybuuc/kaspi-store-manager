# Increment 3 — Management & Control

## Реализовано

- US-15: отчёт по активным товарам и товарам ниже индивидуального порога остатка. Значения берутся из базы при каждом открытии страницы; архивные товары исключены.
- US-17: администратор видит сотрудников и может менять роли `admin` / `employee`. Роль считывается из базы на каждом запросе. Сотрудник не может открыть административные страницы или изменить роль прямым запросом.

## Проверка

Автоматизированные тесты проверяют пустой и меняющийся отчёт, границу порога, исключение архива, сохранение роли, запрет смены собственной роли администратора, CSRF и прямой доступ сотрудника. Запуск: `python -m unittest discover -s tests -v` в виртуальном окружении.

## Ограничения релиза

Этот инкремент не означает готовность к публичному размещению. Для M3 остаётся зарегистрировать результаты всех Must Have NFR, включая проверку HTTPS, нагрузку при 200 пользователях и резервное копирование. Рабочая база и правила хранения данных также требуют решения владельца.
