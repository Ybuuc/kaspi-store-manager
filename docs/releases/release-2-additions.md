# Release 2 — дополнительные функции

- US-12: администратор видит историю цены товара по времени, с прежней и новой ценой и автором. Ранние записи изменения цены, сохранённые в старом формате `edit`, также отображаются.
- US-16: администратор выбирает включительный диапазон дат и видит число и общую сумму сохранённых заказов. Для пустого периода показаны нули. Пока заказы вводятся только как учебные примеры, итог не является подтверждённой выручкой Kaspi.
- US-18: администратор видит журнал изменений товаров, цен, остатков и порогов. Каждая запись содержит время UTC и пользователя. База запрещает изменение и удаление строк журнала через триггеры SQLite.

Проверки: `python -m unittest discover -s tests -v` в виртуальном окружении. Тесты охватывают хронологию и старые записи цен, проверку дат и пустого периода, запрет доступа сотрудника, наличие записей и запрет их правки/удаления.
