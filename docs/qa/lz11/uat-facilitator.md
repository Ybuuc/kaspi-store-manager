# Независимый UAT — памятка координатору

**Статус:** заказчик (другая учебная команда) пока не участвовал; подписи и результаты отсутствуют.

## Приглашение для другой команды

> Приглашаем вашу команду выступить заказчиком на приемке учебного инкремента Kaspi Store Manager в рамках ЛЗ №11. Нужно независимо пройти 10 сценариев по [сценариям UAT](https://github.com/Ybuuc/kaspi-store-manager/blob/lz11-qa-uat-postmortem/docs/qa/lz11/uat-scenarios.md). Для каждого записать PASS / FAIL / BLOCKED, наблюдаемый результат и замечания. Все операции проводятся только с синтетическими данными, без настоящего аккаунта Kaspi. По окончании представитель команды подтверждает решение Accept / Conditional accept / Reject и подписывает протокол. Связь и дату сессии согласуем отдельно.

## Порядок

1. Получить согласие другой команды, назначить её представителя; не приписывать кому-либо участие заочно.
2. Зафиксировать дату, commit SHA, браузер, отдельных тестовых пользователей и учебную SQLite-базу.
3. Передать [UAT-01…UAT-10](uat-scenarios.md), попросить участника самостоятельно выполнить шаги.
4. При каждом фактическом дефекте создать GitHub Issue (UAT-ID, priority P0–P3, steps, expected, actual, screenshot без секретов).
5. Заполнить [протокол приемки](uat-protocol.md), записать согласованное решение и подписи.
6. Закрыть [#67](https://github.com/Ybuuc/kaspi-store-manager/issues/67) **только после** реального проведения и приложения доказательств.

Автотесты GitHub Actions — техническая проверка, а не независимая подпись заказчика.
