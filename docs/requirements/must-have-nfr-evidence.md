# Must Have NFR — результаты проверок для M3

Источник требований: [NFR.md](NFR.md). Результаты ниже относятся к локальной учебной версии. Автоматические тесты запускаются командой `python -m unittest discover -s tests -v` в виртуальном окружении. Последний локальный запуск: **23 теста прошли**. Это не подтверждает поведение публично размещённой системы.

| Требование | Результат | Доказательство и оставшаяся проверка |
|---|---|---|
| NFR-01: чтение p95 ≤ 800 мс при 200 одновременных пользователях | Не проверено | Нет выбранной рабочей среды и нагрузочного теста при 200 пользователях. |
| NFR-02: добавление/изменение товара p95 ≤ 1,2 с | Не проверено | Функциональные тесты проходят; отдельный нагрузочный тест записи не проведён. |
| NFR-03: поиск среди 10 000 товаров < 1 с | Пройдено локально | `test_10000_product_search_under_one_second` проверяет 10 000 товаров через Flask test client; при последнем локальном запуске 0,054 с. Нужна повторная проверка в рабочей среде. |
| NFR-07: блокировка после 5 ошибок на 15 минут | Пройдено локально | `test_five_failed_logins_lock_account` проверяет пять неудачных попыток и отказ при верном пароле. |
| NFR-08: HTTPS для всей аутентифицированной связи | Не проверено | Проверен только флаг `Secure` у cookie при `KSM_HTTPS=1` (`test_secure_session_cookie_configuration`). TLS и перенаправление HTTP должны проверяться после выбора размещения. |
| NFR-09: Employee не получает доступ к admin через URL/API | Пройдено локально | `test_admin_authorization_is_server_side`, `test_admin_can_change_role_and_employee_loses_direct_access`, а также проверки страниц отчётов и журнала. |
| NFR-10: 100% изменений товара/цены/остатка в журнале | Частично проверено | Функциональные тесты проверяют создание, изменение, цену, остаток, порог, архивирование и автора/время; тест журнала проверяет запрет UPDATE/DELETE. Полноту под реальной нагрузкой ещё нужно проверить. |
| NFR-11: полная копия ежедневно, хранение 30 дней | Частично проверено | `backup-db` создаёт согласованную SQLite-копию; `test_backup_command_creates_restorable_snapshot` проверяет целостность и содержимое. Расписание, внешний носитель и 30-дневное хранение зависят от выбранной рабочей среды. |
| NFR-17: дубли SKU = 0 | Пройдено локально | Уникальный индекс `products_sku_ci`; `test_create_edit_search_and_inventory_audit` и `test_add_product_command` отклоняют дубли. |

CI для функциональной поставки: [Application tests](https://github.com/Ybuuc/kaspi-store-manager/actions/runs/41243480241) и [Security scans](https://github.com/Ybuuc/kaspi-store-manager/actions/runs/41243480261) прошли. Для версии с `backup-db` также прошли [Application tests](https://github.com/Ybuuc/kaspi-store-manager/actions/runs/41243763014) и [Security scans](https://github.com/Ybuuc/kaspi-store-manager/actions/runs/41243762991).

**Вывод:** критерий M3 о регистрации результатов выполнен как фиксация фактического состояния; требования NFR-01, NFR-02, NFR-08 и NFR-11 ещё не подтверждены полностью. M3 нельзя закрыть до этих проверок.
