# Kaspi Store Manager — Functional емес талаптар (NFR)

Бұл құжат ЛЗ 4 практикалық бөлігінің артефактісі болып табылады. Барлық талаптар өлшенетін және тексерілетін түрде берілген.

| ID | Санат | Өлшенетін талап | Тексеру әдісі | Priority |
|---|---|---|---|---|
| NFR-01 | Performance | 200 бір мезгілдегі пайдаланушы кезінде оқу операцияларының p95 жауап уақыты 800 мс-тан аспауы тиіс. | Load test | Must |
| NFR-02 | Performance | Тауар қосу және өзгерту операцияларының p95 уақыты 1,2 секундтан аспауы тиіс. | API load test | Must |
| NFR-03 | Performance | 10 000 тауар болған кезде іздеу нәтижесі 1 секундтан аз уақытта қайтарылуы тиіс. | Performance test | Must |
| NFR-04 | Availability | Айлық қолжетімділік жоспарлы жұмыстарды есептемегенде кемінде 99,5% болуы тиіс. | Monitoring | Should |
| NFR-05 | Reliability | Күтпеген сервер ақауынан кейін жоғалуы мүмкін деректер интервалы 15 минуттан аспауы тиіс (RPO ≤ 15 мин). | Backup test | Should |
| NFR-06 | Recoverability | Ақаудан кейін жүйені қалпына келтіру уақыты 60 минуттан аспауы тиіс (RTO ≤ 60 мин). | Recovery test | Should |
| NFR-07 | Security | Қатарынан 5 қате login әрекетінен кейін аккаунтқа кіру 15 минутқа блокталуы тиіс. | Security test | Must |
| NFR-08 | Security | Клиент пен сервер арасындағы барлық аутентификацияланған байланыс HTTPS арқылы шифрлануы тиіс. | Network inspection | Must |
| NFR-09 | Authorization | Employee рөлі әкімшілік функцияларға тікелей URL/API арқылы да кіре алмауы тиіс. | Authorization tests | Must |
| NFR-10 | Auditability | Тауар, баға және қалдықты өзгерту операцияларының 100%-ы audit log ішінде пайдаланушы және уақыт белгісімен сақталуы тиіс. | Audit test | Must |
| NFR-11 | Backup | Деректер базасының толық резервтік көшірмесі тәулігіне кемінде 1 рет жасалып, көшірмелер 30 күн сақталуы тиіс. | Backup log | Must |
| NFR-12 | Usability | Алғаш рет қолданушы 15 минуттық нұсқаулықтан кейін жаңа тауарды 2 минуттан аз уақытта қоса алуы тиіс. | Usability test | Should |
| NFR-13 | Compatibility | Негізгі функциялар релиз кезінде Chrome және Edge браузерлерінің соңғы екі негізгі нұсқасында жұмыс істеуі тиіс. | Cross-browser test | Could |
| NFR-14 | Maintainability | Негізгі business logic үшін автоматтандырылған тесттер code coverage көрсеткішінің кемінде 70%-ын қамтуы тиіс. | Coverage report | Should |
| NFR-15 | Logging | HTTP 5xx серверлік қателерінің 100%-ы timestamp және correlation ID арқылы журналға жазылуы тиіс. | Log verification | Should |
| NFR-16 | Scalability | Тауарлар саны 10 000-нан 50 000-ға өскен кезде негізгі list/search операцияларының p95 уақыты 2 секундтан аспауы тиіс. | Load test | Could |
| NFR-17 | Data Integrity | SKU өрісінің қайталануы 0 жағдай болуы тиіс; деректер базасы деңгейінде unique constraint қолданылады. | DB test | Must |
| NFR-18 | Accessibility | Тауарды іздеу, ашу және редакциялау сияқты негізгі операциялардың 100%-ы пернетақта арқылы орындала алуы тиіс. | Manual UI test | Could |

## MoSCoW
- **Must Have:** NFR-01, NFR-02, NFR-03, NFR-07, NFR-08, NFR-09, NFR-10, NFR-11, NFR-17
- **Should Have:** NFR-04, NFR-05, NFR-06, NFR-12, NFR-14, NFR-15
- **Could Have:** NFR-13, NFR-16, NFR-18

## Definition of Done
User Story тек келесі шарттардың барлығы орындалғанда **Done** күйіне ауыстырылады:
1. Бағдарламалық код жазылған.
2. Acceptance Criteria толық орындалған.
3. Негізгі positive және negative тесттер өткен.
4. Табылған критикалық қателер түзетілген.
5. Өзгерістер GitHub репозиторийіне енгізілген.
6. Review аяқталған.
7. Қатысты NFR талаптары бұзылмаған.
