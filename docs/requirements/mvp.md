# MVP талаптары — Kaspi Store Manager

## Пайдаланушы және мақсат

Негізгі пайдаланушы — дүкен қызметкері. Ол жүйеге кіріп, тауарларды, бағаларды және қоймадағы нақты қалдықты көреді; тауарды қосады, өзгертеді және атауы бойынша табады. Рұқсатсыз пайдаланушы бұл беттерді аша алмайды.

## Тексерілетін функционалдық талаптар

| US | Талап және қабылдау шарты | Тексеру |
|---|---|---|
| [US-01](https://github.com/Ybuuc/kaspi-store-manager/issues/7) | Дұрыс логин/құпиясөз кіруге мүмкіндік береді; бос не қате мән түсінікті қатемен қабылданбайды; қорғалған беттер аутентификациясыз ашылмайды. | Дұрыс, қате, бос кіріс және тікелей URL тесттері. |
| [US-02](https://github.com/Ybuuc/kaspi-store-manager/issues/8) | Тізімде атау, баға, SKU және қалдық көрінеді; бос тізімнің хабары бар; карточка ашылады; 100 тауармен < 2 с. | Тізім, бос күй, сілтеме және жергілікті уақыт тесті. |
| [US-03](https://github.com/Ybuuc/kaspi-store-manager/issues/4) | Міндетті өрістер бос емес, SKU бірегей, баға > 0; дұрыс тауар сақталып, тізімде көрінеді. | Оң және теріс форма тесттері. |
| [US-04](https://github.com/Ybuuc/kaspi-store-manager/issues/9) | Бар тауар өңдеу формасына жүктеледі; міндетті өрістер қайта тексеріледі; қайталанатын SKU қабылданбайды; өзгеріс тізім мен карточкада көрінеді. | Өңдеу және duplicate SKU тесттері. |
| [US-05](https://github.com/Ybuuc/kaspi-store-manager/issues/10) | Карточкада атау, SKU, баға, санат, қалдық бар; тізіммен мәндері сәйкес; жоқ тауар 404 береді. | Карточка, тізім және 404 тесттері. |
| [US-06](https://github.com/Ybuuc/kaspi-store-manager/issues/11) | Атаудың бөлігін регистрге тәуелсіз іздейді; сәйкессіз сұрау бос нәтиже береді; 10 000 тауарда < 1 с. | Іздеу және жергілікті өнімділік тесті. |
| [US-07](https://github.com/Ybuuc/kaspi-store-manager/issues/5) | Қалдық тізім мен карточкада бірдей; 0 дұрыс көрсетіледі; теріс сан сақталмайды. | Оң және теріс қалдық тесттері. |
| [US-08](https://github.com/Ybuuc/kaspi-store-manager/issues/12) | Қалдық тек 0 немесе оң бүтін санға өзгереді; өзгеріс бірден көрінеді; пайдаланушы мен уақыт журналға жазылады. | Жарамды/жарамсыз мән және audit log тесттері. |

Өнімділік тесттері жергілікті Flask test client ішінде орындалады; жүктеме астындағы сервер уақыты бөлек тексеріледі.

## MVP шекарасы

MVP құрамына өнімдер каталогы, іздеу, қойма қалдығын көру және өзгерту, қызметкердің кіруі кіреді. Тапсырыстар, сатылым есептері, нақты Kaspi API интеграциясы және кеңейтілген рөлдер кейінгі инкременттерге қалдырылған. Бұл шекара [story map](story-map.md), [release plan](../planning/lz5/release-plan.md) және [ADR-001](../adr/ADR-001-delivery-model.md) құжаттарымен сәйкес.
