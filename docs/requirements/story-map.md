## MVP RELEASE 1

Толық пайдаланушы жолы:

**Авторизация → Тауарлар тізімі → Тауар қосу → Тауарды өзгерту → Карточканы көру → Атауы бойынша іздеу → Қалдықты көру → Қалдықты өзгерту**

MVP құрамына келесі User Stories кіреді:
- US-01 — Жүйеге кіру
- US-02 — Тауарлар тізімін көру
- US-03 — Жаңа тауар қосу
- US-04 — Тауар ақпаратын өзгерту
- US-05 — Тауар карточкасын көру
- US-06 — Тауарды атауы бойынша іздеу
- US-07 — Қойма қалдығын көру
- US-08 — Қойма қалдығын өзгерту
