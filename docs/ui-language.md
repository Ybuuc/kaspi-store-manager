# Язык интерфейса

Переключатель РУС / ҚАЗ находится в шапке всех страниц, включая страницу входа.
Русский используется по умолчанию. Выбор хранится год в отдельной cookie браузера
и сохраняется после входа, выхода и перезагрузки. Переключение возвращает на ту же
страницу с параметрами поиска; POST защищён CSRF и не перенаправляет на чужие сайты.

`kaspibot/i18n.py` подключает явный перевод статических подписей Jinja, системных
уведомлений и динамических подписей JavaScript. `kaspibot/locales/ui.json` содержит
русские и казахские варианты. `browser-keys.json` ограничивает словарь браузера
используемыми в JavaScript строками; словари вычисляются один раз при запуске.
`static/i18n.js` также задаёт локаль дат. Перевод не обходит и не изменяет весь DOM.

Названия товаров, SKU, имена покупателей, исходные ответы Kaspi, значения форм и
статусы в БД остаются исходными. Переводятся их интерфейсные подписи. Неизвестный
текст диагностики показывается в оригинале. Нельзя переводить URL, ключи API или
условия переходов статусов. Новая подпись требует перевода в обеих локалях; если
она нужна JavaScript, добавьте ключ в browser-keys.json.

Проверки: `python -m unittest discover -s tests -v`; для Chrome без настоящих
запросов Kaspi — `KASPI_CATALOG_BROWSER_TEST=1`; адаптация интерфейса на временной
базе — `python tools/ui_smoke.py --browser-channel chrome`.


## Рабочие представления

Каталог переключается между карточками и таблицей; выбранный вид сохраняется
в cookie браузера. Фильтры по складу, городу цены, предзаказу и локальному учёту
сохраняются в URL, включая переходы по страницам и переключение языка.
Максимум 50 карточек/строк выводятся на страницу. Предзаказ проверяется для того
же выбранного склада; единая цена применяется ко всем городам. Колонки таблицы
и плотность сохраняются в localStorage; после автообновления XML применяются снова.
Доступна локальная прокрутка таблицы, её заголовки закреплены.

На телефонах заказы показываются карточками с раскрываемыми контактами и данными
API. На ПК используется таблица. Поиск номера/покупателя/товара и этап обработки
объединены в одну панель. Подсказки и диагностика источников раскрываются по желанию.
`/attention` доступен только администратору и показывает исходные merchant SKU,
локальные SKU, неподтверждённый архив и защищённую историю. Просмотр не исправляет
и не объединяет записи автоматически. Неизвестный физический остаток обозначен
явно; XML не используется для его подстановки.
